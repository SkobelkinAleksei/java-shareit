# ShareIT 🤝🏼

**Что такое ShareIT?**  
Это веб-сервис, созданный на Java 11 и Spring Boot, позволяющий пользователям находить нужные вещи для временного пользования и делиться своими вещами с другими людьми. Это идеальное решение для тех, кому временно нужны предметы быта, инструменты или оборудование.

## Особенности проекта 👩‍💻👨‍💻

- **Многомодульная архитектура:** Простота поддержки и расширения функциональности.
- **Авторитет владельца:** Пользователь сам определяет доступ к своим вещам.
- **Удобный поиск:** Легкость нахождения нужных предметов по названию и описанию.
- **Система бронирования:** Возможность брать вещи напрокат на определённый срок.
- **Отзывчивость пользователей:** Возможность оставлять отзывы после возврата предмета.
- **Запросы на предметы:** Создание запросов, если нужный предмет отсутствует в системе.

## Технологический стек 🛠️

- **Язык программирования:** Java 11
- **Frameworks:** Spring Boot, Hibernate ORM
- **ORM:** Hibernate
- **Утилиты:** Lombok
- **Контейнеризация:** Docker
- **База данных:** PostgreSQL

## Как начать пользоваться сервисом? 🚀

Чтобы запустить сервис, сделайте следующее:

### Локальная среда разработки:

1. Откройте проект в IntelliJ IDEA.
2. Проведите миграцию базы данных:
   ```sql
   run schema.sql from resources directory of server module
   ```
3. Запустите основной сервис (`shareit-server`) и шлюз (`shareit-gateway`), выбрав классы соответственно:
   ```bash
   ru.practicum.shareit.ShareitServer
   ru.practicum.shareit.ShareitGateway
   ```

### Использование Docker:

1. Запустите контейнеры с помощью Docker Compose.
